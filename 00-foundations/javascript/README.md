# JavaScript — 構文と JS 固有の世界観

> JS を「使える」状態から「**自分の言葉で説明できる**」状態へ持っていくジャンル。Java（学習者が研修で学ぶ予定）と TypeScript を比較対象に、**JS の特徴を際立たせる** 形で進める。

---

## このジャンルが扱う問題

- 「`map` と `forEach` の違いを毎回ググる」を「自分の言葉で説明できる」へ
- なぜ JS は `null` と `undefined` の **両方** が要るのか
- なぜ `==` と `===` が並んでいるのか / どちらを使うべきか
- 「JS は関数が値」とは結局どういうことか（Java のメソッドとどう違うのか）
- `this` が何を指すかが場所で変わる、これは何のため？
- `async/await` の裏で何が起きているのか（Java の `Thread` とは別世界）

---

## 運用方針: アプリ駆動・都度深掘り

このジャンルは **構文を体系順に網羅しない**。代わりに、**応用プロジェクト（`applications/study-board/` 等）で出会った構文** をその都度ここに書き起こす。

```
study-board で `useState` に出会う
        │
        ▼
"const [count, setCount] = ..." の "[]" 何これ？
        │
        ▼
00-concept/03-destructuring.md を書く
        │
        ▼
study-board に戻り、書いたものを参照しながら手を動かす
```

これにより、各構文に **動機** が必ず付く（「なぜ今これを学ぶのか」）。Generation Effect と Active Recall を働かせやすい。

## JS の世界観（8 つの柱）

下記は **構文を学ぶ前に頭に置いておく地図**。各項目は深掘り時に `00-concept/NN-<topic>.md` として独立ファイル化する。

| #   | 柱                          | Java との違い（要点）                                                   | 深掘りファイル（予定）           |
| --- | --------------------------- | ----------------------------------------------------------------------- | -------------------------------- |
| 1   | 変数宣言とスコープ          | Java: 型 + `final`／JS: `const` / `let` / `var` の 3 つ + 巻き上げ      | `00-concept/01-bindings.md`      |
| 2   | 動的型                      | Java は型でメソッド解決／JS は値の型で実行時解決                        | `00-concept/02-dynamic-types.md` |
| 3   | 第一級関数 / 高階関数       | Java 8 のラムダで近づいたが、JS は最初から関数が値                      | `00-concept/04-functions.md`     |
| 4   | クロージャ                  | Java は匿名クラスで final キャプチャ／JS は普通の関数で同等のことが軽い | `00-concept/05-closures.md`      |
| 5   | オブジェクトリテラルと JSON | Java の POJO + getter/setter 不要／中括弧で即値を作れる                 | `00-concept/06-objects.md`       |
| 6   | プロトタイプ継承            | Java のクラス継承とは別物。`class` 構文は糖衣                           | `00-concept/07-prototypes.md`    |
| 7   | イベントループと非同期      | Java の Thread モデルとは別世界。シングルスレッド + キュー              | `00-concept/08-event-loop.md`    |
| 8   | モジュール（ESM）           | Java の `package` / `import` と表面類似、本質は別物（値の export）      | `00-concept/03-modules.md`       |

> 番号はファイル名上の整理用で、**学習順ではない**。学習順は応用プロジェクトに出てきた順に従う。

## Java / TypeScript 比較スタンス

学習者は **Java を研修で学習中（先行学習）**、TypeScript は **少し触れたことがある** 段階。

- **Java 比較**: 「Java ではこう書く予定 → JS はこう違う」と JS 側の特徴を立てる方向。Java を「正解」「基準」として扱わず、**設計思想の違い** を並べる
- **TS 補足**: 各概念で「JS のこの曖昧さを TS はどう型で埋めるか」を 1〜2 行で添える。TS を主役にしない
- **避ける表現**: 「Java と同じ」「Java を知ってるなら簡単」← 表面類似で本質が違う場面が多いため、油断を誘う
